# Local Delivery Dashboard (Direct-to-Consumer)

A web application designed to help users discover and order from nearby restaurants that manage their own independent delivery operations, completely bypassing third-party aggregators like Wolt or Ten Bis.

## Project Context
* **Objective:** Filter out restaurants utilizing corporate delivery networks. The platform must highlight businesses that retain their own delivery drivers, allowing users to support local businesses directly and avoid steep service fees.
* **Key Feature:** A clean dashboard interface displaying comprehensive decision-making metrics for each establishment, alongside direct links to their official proprietary websites.

## Core Evaluation Architecture

To ensure the dashboard provides highly relevant data for ordering decisions, the model must track and display the following metrics for each restaurant profile:

| Metric Group | Specific Data Points |
| :--- | :--- |
| **Identity & Access** | Restaurant Name, Cuisine Type, Direct Website URL (Official Online Ordering System) |
| **Logistics** | Independent Delivery Radius, Minimum Order Value, Flat Delivery Fee, Estimated Fulfillment Time |
| **Decision Variables** | Operating Hours, Dietary Labels (e.g., Vegetarian-friendly, Vegan, Gluten-Free) |

---

## Technical Stack & Constraints
* **Data Sourcing:** Rely heavily on local scraping architectures, official restaurant menus, or open-source community-driven directories rather than third-party API aggregators that filter through mainstream delivery apps.
* **Link Integrity:** All external routing must map directly to the restaurant's primary domain or their white-label booking system (e.g., Tabit, Nibble, or standard internal ordering forms). Absolutely no redirection links to Wolt.

## Code & Development Commands
* **Install Dependencies:** `npm install`
* **Run Development Server:** `npm run dev`
* **Execute Test Suites:** `npm run test`
* **Production Build:** `npm run build`

## Formatting & System Instructions
* Keep the UI clean, highly filterable (by cuisine and dietary restrictions), and optimized for rapid scanning.
* Ensure the code strictly validates the presence of an independent website link before rendering a restaurant profile card on the dashboard.
